# Git Workflow

Git conventions for this project.

## Branch Strategy

- **Trunk-based development** with `main` as production branch
- Feature branches: `feat/description`, `fix/description`, `chore/description`
- Create from `main`, merge back via Pull Request

## Commit Message Format

Follow [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(<scope>): <subject>

<body - 1-2 sentences, optional>
```

### Types

| Type | Use for |
|------|---------|
| `feat` | New features |
| `fix` | Bug fixes |
| `chore` | Maintenance, refactoring |
| `docs` | Documentation |
| `test` | Test changes |
| `perf` | Performance improvements |
| `ci` | CI/CD changes |

### Scopes

Scopes are optional and project-specific. Common patterns:
- Module/package names
- Feature areas
- Service names

### Rules

1. **Title**: Max 50 characters, capitalized, no period
2. **Be specific**: Avoid vague words like "improve", "enhance", "update"
3. **Focus on work**: Describe the change, not file operations
4. **Body**: 1-2 sentences if needed, or omit if title is clear
5. **No AI attribution**: No Co-Authored-By AI, no tool references

### Examples

**Good:**
```
feat(auth): Add OAuth2 login support

Users can now authenticate via Google and GitHub OAuth providers.
```

```
fix(api): Handle timeout during webhook delivery
```

**Bad:**
```
chore(config): Update configuration  # Vague - what update?
docs(plans): Add implementation plan  # Focus on file, not work
```

## AI Attribution Policy

**STRICTLY FORBIDDEN** - Never include in commits or PRs:
- `Co-Authored-By: Claude`, `Co-Authored-By: GPT`, or any AI
- AI-related emojis
- "Generated by", "Created with", or similar phrases
- Any reference to AI tools (Claude, ChatGPT, Copilot, etc.)

Commits and PRs must appear as human-authored work.

## Development Workflow

### Starting Work

```bash
git checkout main
git pull origin main
git checkout -b feat/my-feature
```

### Making Commits

```bash
# Stage changes
git add <files>

# Check what's staged
git diff --cached

# Commit (or use /commit skill)
git commit -m "feat(scope): Description"
```

### Creating Pull Requests

```bash
# Push branch
git push -u origin feat/my-feature

# Create PR (or use /pr-create skill)
gh pr create --base main --title "feat(scope): Description"
```

## Quick Reference

```bash
# View staged changes
git diff --cached

# Amend last commit (unpushed only)
git commit --amend

# Undo last commit (keep changes)
git reset --soft HEAD~1

# Check current branch
git branch --show-current
```
